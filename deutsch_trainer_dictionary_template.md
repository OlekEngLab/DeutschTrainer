# Deutsch Trainer — шаблон для создания словаря v6

Ты создаёшь словарь для приложения **Deutsch Trainer**.

## Что нужно сделать

Создай словарь по теме, которую укажет пользователь.

### Строгие требования

1. Ровно **9 слов**.
2. Для каждого слова — от 1 до 4 самостоятельных допустимых русских переводов.
3. Не объединяй варианты перевода в одну строку через `/` или `;`: каждый вариант должен быть отдельным элементом массива `ru`.
4. Для каждого слова — короткая подсказка `help` на русском. Подсказка не должна просто повторять перевод.
5. Для каждого слова — ровно **3 предложения**.
6. Каждое предложение имеет уровень `A1`, `A2`, `B1` или `B2`.
7. Предложения должны быть естественными и действительно показывать употребление данного слова.
8. Три предложения должны отличаться по контексту, а не быть простым повторением одной фразы.
9. Для каждого предложения дай естественный русский перевод.
10. Если слово имеет несколько значений, включай только полезные для выбранной темы значения.
11. Не добавляй лишних слов, предложений или полей.
12. `id` словаря должен быть уникальным и состоять из латинских букв, цифр, `_` или `-`.
13. `de` каждого слова должен быть уникальным внутри словаря.
14. Ответ должен быть **только валидным JSON**, без пояснений до или после него.

## Уровни предложений

- **A1** — простая лексика и базовая грамматика.
- **A2** — бытовые ситуации и более длинные фразы.
- **B1** — придаточные предложения, связанные высказывания, более естественная речь.
- **B2** — сложные конструкции и более продвинутая лексика.

Не обязательно использовать все четыре уровня. Например, три предложения могут быть `A1 + A2 + B1` или `A2 + B1 + B2`.

## Формат JSON

```json
{
  "id": "THEMA_001",
  "title": "Название темы",
  "sourceLanguage": "de",
  "targetLanguage": "ru",
  "words": [
    {
      "de": "deutsches_wort",
      "ru": [
        "перевод 1",
        "перевод 2"
      ],
      "help": "Короткая подсказка без прямого раскрытия ответа."
    }
  ],
  "sentences": [
    {
      "word": "deutsches_wort",
      "level": "A1",
      "de": "Немецкое предложение.",
      "ru": "Естественный русский перевод."
    }
  ]
}
```

## Обязательная проверка перед выдачей JSON

Проверь:

- `words` содержит ровно 9 элементов;
- у каждого слова есть `de`, `ru` и `help`;
- `ru` — массив допустимых переводов;
- `sentences` содержит ровно 27 элементов;
- для каждого `words[].de` есть ровно 3 предложения;
- значение `sentences[].word` точно совпадает с `words[].de`;
- каждый `level` равен только `A1`, `A2`, `B1` или `B2`;
- JSON синтаксически корректен.

Не добавляй комментарии и не изменяй структуру JSON.
