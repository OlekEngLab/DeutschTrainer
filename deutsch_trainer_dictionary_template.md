# Шаблон для создания словаря Deutsch Trainer через ИИ

Скопируйте текст ниже целиком, замените `<ТЕМА>` и, если нужно, список слов,
и отправьте любому ИИ-чату. На выходе должен получиться готовый JSON-файл —
сохраните его с расширением `.json` и загрузите в тренажёр кнопкой
«📚 Загрузить словарь».

Схема ниже соответствует текущей версии тренажёра. Файл, не подходящий под
неё, будет отклонён с сообщением об ошибке.

---

## Промпт для ИИ

```
Сгенерируй словарь для тренажёра немецкого языка в формате JSON по теме:
<ТЕМА, например: "приставочные глаголы bringen" или "Perfekt неправильных глаголов">

Слова для включения (если не указано — подбери сам 9 штук по теме):
<СПИСОК СЛОВ или "подбери сам">

Строго следуй этой JSON-схеме, без пояснений и без markdown-обёртки ```:

{
  "id": "уникальный-идентификатор-латиницей-без-пробелов",
  "title": "Короткое название темы",
  "words": [
    {
      "de": "немецкое слово или конструкция",
      "ru": ["перевод1", "перевод2 (если есть синонимы)"],
      "help": "краткое объяснение значения по-русски, без прямого перевода слова"
    }
  ],
  "sentences": [
    {
      "word": "должно точно совпадать с одним из de в words",
      "level": "A1 | A2 | B1 | B2",
      "de": "немецкое предложение с этим словом",
      "ru": "перевод предложения на русский"
    }
  ]
}

Требования (все обязательны, файл не пройдёт проверку без них):
1. "id" — уникальная строка латиницей, без пробелов и спецсимволов
   (например: "bringen-praefixe"). Не должна совпадать с id других словарей.
2. "words" — РОВНО 9 слов, без повторов внутри массива.
3. "ru" у каждого слова — массив (даже если перевод один: ["перевод"]).
4. "help" — не перевод слова, а объяснение его смысла своими словами
   по-русски (например, для "ausmachen": "прекратить работу прибора или
   договориться о чём-либо"). Используется как подсказка, когда учащийся
   не может вспомнить слово.
5. Для КАЖДОГО слова из "words" должно быть РОВНО 3 предложения в
   "sentences" — не больше и не меньше.
6. Желательно (не обязательно строго технически, но важно педагогически):
   среди трёх предложений для слова — одно уровня A1, одно A2, одно B1,
   от простого к сложному. Если сделать одинаковый уровень для всех трёх —
   упражнение будет либо слишком лёгким, либо слишком сложным на любом
   выбранном уровне урока.
7. Значение "word" в предложении должно ТОЧНО совпадать со значением "de"
   соответствующего слова (тот же регистр, без опечаток).
8. "level" — только одно из значений: A1, A2, B1, B2.
9. "ru" у предложения — обычная строка (не массив).
10. Предложения — естественные, без сленга, показывающие типичное
    употребление слова в контексте.
11. Верни ТОЛЬКО валидный JSON, без комментариев, без текста до и после.
```

## Пример готового результата (по образцу словаря machen)

```json
{
  "id": "bringen-praefixe",
  "title": "bringen & Präfixe",
  "words": [
    {
      "de": "bringen",
      "ru": ["приносить", "доставлять"],
      "help": "переместить что-либо или кого-либо из одного места в другое"
    },
    {
      "de": "mitbringen",
      "ru": ["приносить с собой"],
      "help": "принести что-либо, отправляясь куда-то, вместе с собой"
    }
  ],
  "sentences": [
    { "word": "bringen", "level": "A1", "de": "Kannst du mir Wasser bringen?", "ru": "Можешь принести мне воды?" },
    { "word": "bringen", "level": "A2", "de": "Ich bringe das Buch morgen zurück.", "ru": "Я верну книгу завтра." },
    { "word": "bringen", "level": "B1", "de": "Er hat versprochen, die Unterlagen persönlich vorbeizubringen.", "ru": "Он пообещал принести документы лично." },
    { "word": "mitbringen", "level": "A1", "de": "Bring bitte einen Kuchen mit.", "ru": "Принеси, пожалуйста, торт с собой." },
    { "word": "mitbringen", "level": "A2", "de": "Er hat seinen Freund mitgebracht.", "ru": "Он привёл с собой друга." },
    { "word": "mitbringen", "level": "B1", "de": "Es wäre schön, wenn du gute Laune mitbringen könntest.", "ru": "Было бы хорошо, если бы ты принёс с собой хорошее настроение." }
  ]
}
```

(В реальном словаре нужно 9 слов, здесь для краткости показано 2.)

## Что проверяет тренажёр при загрузке

Файл будет отклонён с сообщением об ошибке, если:
- нет `id` или `title`;
- `words` — не массив или в нём не ровно 9 элементов;
- слово пустое или повторяется;
- у слова `ru` — не массив, или массив пустой;
- у слова нет `help` (строки);
- для какого-то слова не ровно 3 предложения в `sentences`;
- у предложения нет допустимого `level`, `de` или `ru`.

Проверка НЕ требует конкретного распределения предложений по уровням
(A1/A2/B1) — это указано в промпте как педагогическая рекомендация, а не
техническое ограничение. Но если все три предложения будут одного уровня,
слово может оказаться либо слишком лёгким, либо слишком сложным на других
уровнях урока (при нехватке подходящих по уровню предложений тренажёр
автоматически возьмёт все три, независимо от уровня, — так что урок не
сломается, но качество подбора пострадает).

## О поле "id"

Используется для хранения прогресса отдельно по каждому словарю (в
локальном хранилище браузера) и для того, чтобы не добавлять один и тот же
словарь дважды. Делайте его уникальным и не меняйте у уже загруженного
словаря — иначе прогресс по нему "потеряется" (фактически создастся как
новый словарь).
